# 触发 Skill 的示例提示词

本文档收集了能触发各 skill 的真实提示词。可作为调试或推广素材。

> 当你添加新 skill 时，请同时在这里补充 3-5 条触发样例。

## 通用建议

- **明确动词**：动词越具体越容易触发（"重构" 比 "改一下" 更明确）
- **领域名词**：包含 skill description 中的关键词
- **附带上下文**：贴上文件名或错误信息能显著提升匹配准确率
